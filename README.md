## ⏱️ Algorithm Complexity

Some of the important algorithms and their typical time complexities are:

| Algorithm / Operation        | Time Complexity  |
| ---------------------------- | ---------------- |
| Linear Search                | O(n)             |
| Binary Search                | O(log n)         |
| Stack Push                   | O(1)             |
| Stack Pop                    | O(1)             |
| Queue Enqueue                | O(1)             |
| Queue Dequeue                | O(1)             |
| BST Search                   | O(log n) average |
| Heap Insertion               | O(log n)         |
| Brute Force Pattern Matching | O(n × m)         |

> The actual complexity may vary depending on the implementation and input conditions.

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/sebak55/DSA.git
```

### 2. Open the Repository

```bash
cd DSA
```

### 3. Compile a C Program

For example:

```bash
gcc "Linear search.c" -o linear_search
```

### 4. Run the Program

On Linux/macOS:

```bash
./linear_search
```

On Windows:

```bash
linear_search.exe
```
