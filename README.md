## ⏱️ Algorithm Complexity

Some of the important algorithms and their typical time complexities are:

| Algorithm / Operation | Time Complexity |
|---|---|
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Stack Push | O(1) |
| Stack Pop | O(1) |
| Queue Enqueue | O(1) |
| Queue Dequeue | O(1) |
| BST Search | O(log n) average |
| Heap Insertion | O(log n) |
| Brute Force Pattern Matching | O(n × m) |
| Bubble Sort | O(n²) |
| Selection Sort | O(n²) |
| Insertion Sort | O(n²) |
| Merge Sort | O(n log n) |
| Quick Sort | O(n log n) average |
| Heap Sort | O(n log n) |
| BFS | O(V + E) |
| DFS | O(V + E) |
| Dijkstra's Algorithm | O((V + E) log V) |

> The actual complexity may vary depending on the implementation and input conditions.
